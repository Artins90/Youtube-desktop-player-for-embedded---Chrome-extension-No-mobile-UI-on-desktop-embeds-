# YouTube Desktop Player for Embedded Videos

A Chrome extension that restores YouTube’s classic desktop UI in embedded players, preventing the mobile-style interface from appearing on desktop.

## Installation

1. Copy the extension folder to a permanent location. Chrome loads the extension from that folder every time it opens, so don’t move or delete the folder after installation.
2. Open `chrome://extensions/` in Chrome.
3. Turn on **Developer mode** using the switch in the top-right corner.
4. Select **Load unpacked**.
5. Choose the extension folder: `Youtube desktop player for embedded`.
